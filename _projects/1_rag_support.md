- Designed retrieval, chunking, and prompt orchestration for insurance-domain queries
- Containerized with Docker and deployed on Azure Container Apps with CI/CD

**Stack:** Python · FastAPI · GPT-4 / Azure OpenAI · Docker · Azure · Vector DB
