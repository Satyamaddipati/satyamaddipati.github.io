# Final résumé

Place the actual final PDF at `assets/resume/Satya_Maddipati_Resume.pdf`.
No final file is currently supplied.

Run `python3 scripts/build_resume.py` after adding or removing it to update
static links. This utility checks the PDF signature and never generates,
replaces, or edits a PDF. All links work without JavaScript.

The old `resume/satya-maddipati-resume.pdf` is a pre-existing generated draft,
unchanged and unlinked. It remains reachable by its old direct URL if published.
The redesign keeps `/resume/` available with readable background information.
